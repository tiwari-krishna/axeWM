# Axe WM

A minimal river based wayland window manager like suckless DWM.
Originally started from the [ANVL](https://git.auoggi.com/linux/anvl).
Then added a lot of random stuff mostly meant for me.

## Build Process

```sh
make build
```

Later might need to remove .build folder to rebuild.

## How to run??

Needs river 0.40 or higher.

```sh
river -c pathToRepo/.build/axe
```

## Configuration

Make changes to the config.h file and recompile. Keymaps and all the good stuff are in there. Feel free to add features in there as well as per need.
